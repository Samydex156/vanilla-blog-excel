Función AÑO()

Devuelve el año correspondiente a una fecha determinada. El año se expresa como número entero en el rango de 1900 a 9999.

Sintaxis

=AÑO(fecha_número)
fecha_número: La fecha de la que se desea obtener el año. Debe introducirse como referencia a una celda con fecha, o como resultado de otras funciones de fecha (obligatorio).

Ejemplo Práctico

Si la celda A1 contiene la fecha 18/06/2026 y aplicas la siguiente fórmula:

=AÑO(A1)

El resultado devuelto será 2026.

Observaciones

  • Esta función se utiliza comúnmente para calcular antigüedades o diferencias en años restando dos fechas: =AÑO(HOY()) - AÑO(A1).
  • Si el argumento provisto no es una fecha válida o contiene texto que no se puede interpretar, la función devolverá el error #¡VALOR!.
